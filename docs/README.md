# docs 目录说明

这个目录目前按“正式提交材料、详细设计、参考资料、内部辅助材料”四类整理，优先查看正式提交包。

## 目录导航

### `01_初赛提交包`

这是当前最重要的目录，用于初赛正式提交。里面已经整理好以下材料：

- `00_作品简介`
- `01_总体架构设计`
- `02_Agent身份清单`
- `03_Skill契约`
- `04_方案PPT`

如果只看一套最终提交材料，直接从这个目录进入即可。

### `02_详细设计`

这是在总体架构设计基础上继续下沉后的实施级设计文档，重点补充了以下内容：

- AgentTeams 的对象模型和运行方式
- `repo_indexer` 的首次全量、后续增量、必要时重建策略
- Skill 详细设计与生命周期
- RAG、MCP / 等价工具契约、可观测、开源与合规
- 服务拆分、数据库、部署和开发实施路径

当你需要继续细化实现方案、准备后续 Demo 或答辩细节时，优先看这个目录。

### `00_参考资料`

这里存放比赛原始参考材料和前期思路，用于回看赛题要求与方案来源：

- `赛道一介绍.html`
- `赛道一参赛手册.pdf`
- `赛道一思路.md`
- `赛道二介绍.pdf`

如果后续要再次核对比赛要求，直接从这里取材料。

### `03_答辩讲稿提纲.md`

这是内部辅助材料，不属于正式初赛提交件。它用于后续准备讲解和答辩时快速梳理表达逻辑。

## 建议的查看顺序

第一次查看建议按下面顺序阅读：

1. `01_初赛提交包`
2. `02_详细设计`
3. `00_参考资料`
4. `03_答辩讲稿提纲.md`

## 当前整理原则

- 正式提交材料统一放在 `01_初赛提交包`
- 比赛原始资料统一放在 `00_参考资料`
- 非正式但仍有价值的补充设计单独保留在 `02_详细设计`
- 仅用于内部讲解的材料不放入提交包
